### Задание 1. - Вырезать фигуру девушки и поместить на другой фон

Учебное видео RU - [Gimp tutorial: как убрать фон в изображении и изменить его. Два способа](https://www.youtube.com/watch?v=pQtw2NvSZZE)
1. Найдите в поисковике изображение девушки в деловом костюме на белом фоне
2. Откройте бесплатный графический редактор `Gimp` и вставьте выбранное изображение через `Файл \ Создать \ Из буфера обмена`
3. Выберите инструмент `Волшебная палочка` и используйте его на изображение девушки, удалите фон - нажав клавишу `Delete`
4. В правом нижнем углу проверьте есть ли альфа-канал (правая кнопка мыши - контекстное меню - Добавить альфа канал)
5. Используйте меню `Выделение \ Инвертировать выделение` + `Растушевать` (5-10 px) + `Уменьшить выделение` (1-2-5 px)
6. Выберите инструмент `Размазывание` (палец) и используйте его на изображение девушки (по волосам и другим местам, чтобы удалить фоновые артифакты, пятна фона)
7. Можете увеличить размер изображения - используя `Изображение \ Размер холста`, чтобы ширина была больше высоты
8. Добавьте еще один слой и поместите его ниже слоя с контуром девушки
